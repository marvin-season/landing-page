# 开放世界头像

头像来自 [phaticusthiccy/avatar-dataset](https://github.com/phaticusthiccy/avatar-dataset/tree/master/anime) 的 anime 图片目录，已裁切为头像并缩放为 160 × 160 WebP，运行时仅加载本地资源。

角色映射在 src/app/agent/worlds/_components/character-avatar.tsx，按角色 ID 固定选择；未配置的新角色按 ID 稳定分配。已有世界无需迁移。
