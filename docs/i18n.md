# internationalization

## Locale source of truth

UI locales live in `src/lib/i18n/locales.ts`. `lingui.config.ts` and routing / language switcher code import from there.

Supported locales: `en`, `zh`, `ja`, `ko`, `ru`, `fr`, `ar`, `ug`, plus `pseudo` for Lingui pseudo-localization. The language switcher hides `pseudo`. `ar` and `ug` are RTL; `getLocaleDir` sets `dir` on the `[lang]` layout.

Knowledge document translation targets (`en` / `ja` / `ko` / `zh-Hans` / `ru` / `fr` / `ar` / `ug`) are a separate list in `src/app/[lang]/knowledge/_components/document/translation-language.ts`.

## BBQ

Unprefixed `/bookkeeping` and its descendants redirect to `/zh/bookkeeping`, preserving the remaining path and query string. Explicit locale prefixes are retained, including `/en/bookkeeping`; BBQ links always include the selected locale so English navigation does not trigger the Chinese redirect. Legacy `/admin/bbq` URLs permanently redirect to the equivalent bookkeeping route with the locale, remaining path and query preserved. Each real language has its own canonical URL and hreflang alternatives in page metadata and the sitemap. Other routes retain the existing unprefixed English behavior.

BBQ uses the same eight UI locales and language switcher. Page metadata, UI messages, validation errors, photo and backup prompts, calendar labels, and calorie summaries are translated with Lingui. Stored item names, units, record snapshots, and Shanghai business-day boundaries are unchanged. The installed PWA retains its Chinese start URL and manifest; see [bbq-pwa.md](./bbq-pwa.md).

Client components use `Trans` and `useLingui` from `@lingui/react/macro`. Helpers and metadata use `` i18n._(msg`…`) `` with an explicit instance; avoid the deprecated `t(i18n)` macro overload.

## i18n support

i18n code example:

```tsx
import { Trans } from "@lingui/react/macro";

<Trans>Hello, world!</Trans>
```
extract i18n messages:

```bash
nr lingui:extract
```
manage i18n messages:
```js
// @src/locales/xx.po
msgid "Hello, world!"
msgstr "你好，世界！"
```

for production, compile i18n messages:
```bash
nr lingui:compile
```
