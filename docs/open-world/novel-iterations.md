# 小说模式产品迭代

小说模式是单人长篇续写台。一个 Writer 按作者这一次给出的要求写一章连续正文。角色是创作资料，不是轮流发言的角色。作者自己决定何时续写、润色或整理剧情，系统不自动连写。正文按章节留在本机；开发环境可以和服务器 TXT 对账。

迭代只服务这四件事：

1. 看清当前写到哪一章、这一章有多长、当时提了什么要求。
2. 用更短的操作写下一次要求，或复用已经写过的要求。
3. 一次生成或整理的结果在作者确认前不丢失，确认后才进入正文。
4. 改已有章节时保持章序和后文，不把整本书重写一遍。

新特性、功能优化、界面优化都可以进入下表。不服务上面四件事的需求不进入下表。行为细节以 [小说模式](./novel-mode.md) 为准。本表只记录迭代和状态。

状态只有三种：

| 状态 | 含义 |
| --- | --- |
| 已交付 | 行为已经在当前提交的产品里 |
| 已实现 | 工作区里已有代码，对应验收已过，还没提交，或还没在浏览器里走过 |
| 未开始 | 已列入表，还没有改代码 |
