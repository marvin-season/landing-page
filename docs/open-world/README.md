# 开放世界文档

入口：`/agent/worlds`（作品大厅）与 `/agent/worlds/[roomId]`（作品详情），沿用 `/agent` 的登录保护。

剧本和小说共用世界模板、世界设定编辑器与角色资料。创建作品时选择类型，类型写入服务端，创建后不能切换：

- **剧本**：多位 NPC 用对白接续，旁白可选；调度器在服务端选人，记录保存在服务端房间存档。
- **小说**：一个 Writer 按章创作，作者手动触发；章节与小说设定保存在当前浏览器的 IndexedDB。
