# 开放世界文档

开放世界入口：`/agent/worlds`。剧本和小说共用世界模板与设定，创建作品时选择类型，创建后不能切换。剧本由角色与可选旁白接续对话，记录保存在服务端；小说由一个 Writer 按章生成，正文保存在当前浏览器。

- [剧本群聊使用与实现](./group-chat.md)：操作流程、代理配置、运行边界和验证命令。
- [开放世界运行架构](./architecture.md)：房间类型、剧本调度、角色上下文和小说生成链路。
- [小说模式架构](./novel-mode.md)：章节生成、润色、续写上下文、续写分支、存档及导出。
- [开放世界流程图](./flowcharts.md)：剧本调度、角色上下文、接口链路和小说章节生成时序。
- [剧本群聊初版需求](./agent-group-chat-prd.md)：历史需求和设计取舍。当前行为以上述文档为准。

项目级信息见[文档索引](../README.md)和[架构总览](../architecture.md)。
